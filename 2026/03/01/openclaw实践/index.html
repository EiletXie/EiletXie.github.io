openclaw实践

发表于 2026-03-01 阅读次数： 本文字数： 1k 阅读时长 ≈ 1 分钟

前言

最近 OpenClaw 特别火，刷到几个短视频都在阐述这个类似 AGI 的工具，于是打算本地部署测试一下。

个人测试下来感觉适合有点说不出来的中庸，比较适合有点钱的普通人来远程处理电脑资料、进行一些基础总结等。

为什么这么说？你需要经常切换 session，不然加上上下文的传递，我 3、4 次对话就花了 20 万的 Tokens，特别费 token，并且还只是一些简短的任务要求。对模型要求高。如果是做产品，还是用 Cursor 好点。

测试流程

整理测试流程如下：

  1. 本地部署 OpenClaw
  2. 对接第三方，这里使用飞书
  3. 进行本地电脑 OpenClaw 测试，和第三方对接测试。

1. 首先是部署 OpenClaw

我这边装的是中文社区版的，跟海外版几乎一致，只是做了一些配置的中文转换而已，方便安装使用。

安装地址：https://clawd.org.cn/#install

我本地是 Windows 10 系统，所以按照要求，在 PowerShell 中执行该命令即可。注意 Node.js 的版本要求是 22 以上。

等几秒即可安装成功。

接下来就是配置模型、第三方这些。我建议是你第一次玩这个，模型暂时就用 Qwen 的免费模型即可，根据给的链接去注册一下千问的账号就 auth 成功了；其他对接第三方等配置的先跳过，直接一路 enter 启动就行。

启动问题

我本地默认安装 OpenClaw 启动失败了，报 1006，查看日志也没具体描述，就是 gateway status 是 error。可能是 Windows 的 bug 或者防火墙的问题，我重新执行 openclaw gateway –port 18789 就可以正常启动。

2. 对接第三方（飞书）

参考 OpenClaw 对接飞书文章： https://cloud.tencent.com/developer/article/2626160

飞书对接的目的是通过配置一个飞书 App 的机器人，实现信息传递，本质只是远程调用小龙虾助理干活，将信息返回。

你将飞书的 App ID 和 Secret Key 配置给 OpenClaw（可以直接在小龙虾的聊天窗口把信息给他，他会自动配置）。

可以参考上述文章配置飞书机器人，权限可以全部开启作为测试。

3. 测试对接

使用飞书发送消息，要求小龙虾给我搜最新的伊朗新闻，然后截图发送给我。期间我还提示它，由于没开 VPN，不要用 Google 来搜，要用必应。它也会理解处理。
