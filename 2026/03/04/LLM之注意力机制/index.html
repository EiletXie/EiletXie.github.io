LLM之注意力机制

发表于 2026-03-04 阅读次数： 本文字数： 2.8k 阅读时长 ≈ 3 分钟

LLM 之注意力机制（Attention）

1. 什么是注意力机制？

大模型中的 Attention（注意力）机制 是现代深度学习，尤其是自然语言处理（NLP）和生成式人工智能（如大语言模型 LLMs）的核心组件之一。

它最初在 2017 年由 Vaswani 等人在论文《Attention Is All You Need》中提出，并催生了 Transformer 架构，成为当前几乎所有大模型（如 GPT、BERT、LLaMA、Qwen 等）的基础。

一、直观理解：什么是“注意力”？

想象你在阅读一句话：

“The cat sat on the mat.”

当你读到 “sat” 这个词时，你的大脑会自动关注前面的 “cat” 和后面的 “mat”，因为它们对理解 “sat” 的含义至关重要。

这种 动态地关注输入序列中某些部分的能力，就是注意力机制要模拟的行为。

核心思想：不是对所有输入一视同仁，而是根据当前任务的需要，给不同位置的输入分配不同的权重（重要性）。

二、基本形式：Scaled Dot-Product Attention

这是 Transformer 中使用的标准 Attention 形式，公式如下：

$$
\text{Attention}(Q, K, V) = \text{softmax}\left( \frac{QK^\top}{\sqrt{d_k}} \right) V
$$

其中：

  • Q（Query，查询）：代表当前要处理的 token 的“需求”。
  • K（Key，键）：代表每个输入 token 的“身份标识”。
  • V（Value，值）：代表每个输入 token 的“实际内容”。
  • $d_k$：Key 的维度，用于缩放（防止点积过大导致 softmax 梯度消失）。

步骤分解：

  1. 计算相似度：对每个 Query 与所有 Key 做点积，得到一个“相关性分数”矩阵。
    例如：当前词 “sat” 的 Query 与 “cat”、“on”、“mat” 等的 Key 计算相似度。

  2. 缩放：除以 $\sqrt{d_k}$，使梯度更稳定。

  3. Softmax：将分数转化为概率分布（即注意力权重），总和为 1。

⚠️ 注意：这里的 $K^\top$ 是对每个样本的 Key 矩阵做转置（交换最后两个维度），而不是对整个 batch 张量做全局转置。

通俗来说

注意力机制是大模型根据当前输入的词语关联推算下一个词语的核心机制。

例如：

“The cat sat on the…”

大模型会根据前面的这几个词语，通过注意力机制推算其他词语的关联性，计算出权重最高的应该是 “mat” 这个单词。

大体流程：对这 5 个词做自注意力（Self-Attention）

❓ 什么是“自注意力”？

→ 每个词都当一次“听众”（Query），去听所有词（包括自己）说话（Key/Value）。

比如，处理 “sat”（位置 2）时：

  • 它的 Query = $W_Q \times e_3$
  • 所有词的 Key = $[W_K \times e_1, W_K \times e_2, W_K \times e_3, W_K \times e_4, W_K \times e_5]$
  • 所有词的 Value = $[W_V \times e_1, \dots, W_V \times e_5]$

然后计算：

  • “sat” 和 “The” 相关吗？→ 点积$(Q_{\text{sat}}, K_{\text{The}})$
  • “sat” 和 “cat” 相关吗？→ 很相关！（主语）
  • “sat” 和 “on” 相关吗？→ 也很相关！（介词）
  • “sat” 和 “the” 相关吗？→ 可能弱一些

→ 得到一组权重，比如：[0.1, 0.4, 0.2, 0.3, 0.0]
→ 用这些权重加权求和 Value，得到 “sat” 的新表示 $h_2$，它已经融合了“cat”和“on”的信息！

✅ 所以：每个词的新表示 = 整个句子上下文的浓缩版，不是孤立的！

模型会对每个位置（0~4）都做一遍这个过程，得到 5 个新向量：$[h_0, h_1, h_2, h_3, h_4]$

第三步：用这些表示来预测下一个词（“mat”）

现在模型要预测第 6 个词（位置 5）。关键点来了：生成新词时，也要用注意力机制！而且要用到之前所有词（包括刚算出的 $h_0 \sim h_4$）

具体怎么做？

  1. 模型把当前已有的 5 个词（“The cat sat on the”）作为输入。
  2. 通过多层 Transformer（每层都有 Self-Attention + 前馈网络），得到它们的深层表示。
  3. 取最后一个位置（即 “the”）的输出向量，送入一个“语言模型头”（LM Head）。
  4. LM Head 输出一个词汇表上的概率分布，比如：
    • “mat”: 85%
    • “floor”: 5%
    • “chair”: 3%
    • …其他很低
  5. → 模型选择概率最高的 “mat” 作为下一个词。

三、多头注意力（Multi-Head Attention）

单一 Attention 可能只捕捉一种类型的依赖关系（比如语法或语义）。为了增强模型表达能力，Transformer 引入多头机制：

  • 将 Q、K、V 分别通过多个线性变换（即多个“头”）投影到不同子空间。
  • 每个头独立计算 Attention。
  • 最后将所有头的输出拼接起来，再通过一个线性层融合。

公式表示：

$$
\text{MultiHead}(Q, K, V) = \text{Concat}(\text{head}_1, \dots, \text{head}_h) W^O
$$
其中：
$$
\text{head}_i = \text{Attention}(Q W_i^Q, K W_i^K, V W_i^V)
$$

多头机制让模型能同时关注不同位置、不同语义层面的信息，例如一个头关注主谓关系，另一个头关注指代关系。

🧠 类比解释（用开会打比方）：

想象你在开一个会议，讨论一段话（比如：“她把书放在桌子上，然后离开了房间。”）的意思。

  • 单头注意力：只有一个人（一个“注意力头”）来分析这句话，他可能只关注“她”和“离开”，忽略了“书”和“桌子”的关系。
  • 多头注意力：请来 8 位专家（假设有 8 个头），每人戴一副不同颜色的眼镜：
    • 专家1：关注主语和动词（“她…离开”）
    • 专家2：关注宾语和位置（“书…桌子”）
    • 专家3：关注时间顺序（“先放书，再离开”）
    • ……

每位专家独立分析，最后大家把自己的笔记（注意力结果）汇总，形成一个全面、多角度的理解。

四、为什么注意力机制强大？

优势 说明
全局依赖建模 RNN 只能逐词传递信息，长距离依赖会衰减；注意力让任意两个词直接建立联系（无论相隔多远）
可并行计算 RNN 必须顺序处理，注意力所有词对可同时计算 → 训练更快
可解释性强 可视化注意力权重，看到模型“关注了哪些词”（例如：翻译 “it” 时，高亮 “cat” 而非 “mat”）
灵活适配任务 机器翻译、文本摘要、问答、图像描述……都能用

总结

注意力机制的本质：
给定一个目标（Query），从一堆信息（Key-Value 对）中，动态地、有选择地提取最相关的内容。

它不是“记住所有”，而是“知道该关注什么”——这正是智能的核心之一。
